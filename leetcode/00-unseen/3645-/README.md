# 3645. 最优激活顺序得到的最大总和

记录：独立 · 未超时 · 首交通过

## 我的思考

题意：长度为 n 的数组 value、limit，初始全部非活跃。激活元素 i 要求当前活跃数严格小于 limit[i]，激活后 value[i] 计入总和。每次激活后若活跃数变为 x，则所有 limit[j] ≤ x 的元素永久失效（包括已活跃的）。求最大总和。

约束：n ≤ 1e5，value[i] ≤ 1e5，1 ≤ limit[i] ≤ n。

解法一（模拟）：按 limit 分组，每组用大顶堆存 value。limit 从小到大处理，每组从大到小激活，同时模拟失效过程：
- `currActive`：当前活跃数；`maxActive`：历史最大活跃数，即失效阈值；`actives[j]`：limit = j 且仍活跃的元素个数。
- 每次激活后，若 `currActive > maxActive`，则 `maxActive++`，再减去 `actives[maxActive]`（这一组整组失效）。
- 当 `maxActive == i` 时，第 i 组不能再激活，break。

解法二（简化）：每组只保留最大的 limit 个 value。用小顶堆维护，超过容量就弹出堆顶并从答案中减去。答案为各组前 L 大之和。

## 复杂度

- 时间：O(n log n)，两种解法相同。
- 空间：O(n)。

## 注意

- 解法二的正确性依赖上界：limit = L 的元素最多能激活 L 个。激活这一组时，已激活的同组元素都还活着；活跃数一旦达到 L，整组永久失效，之后也不能再激活。可达性由解法一的模拟构造保证（limit 升序、组内降序）。面试时如果直接写解法二，要先说清楚这个上界。
- 总和最大约 1e10，ans 用 long。
- 解法一状态多且相互耦合，正确性依赖不变式 `currActive ≤ maxActive ≤ i-1`（每组开始时成立），容易写错。
