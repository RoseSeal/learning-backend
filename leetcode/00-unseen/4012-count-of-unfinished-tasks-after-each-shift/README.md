# 4012. Count of Unfinished Tasks After Each Shift

记录：独立 · 未标超时 · 首交未记录（迁移自旧 unseen 记录）

## 题意

tasks 按顺序处理，shifts[j] 为第 j 个班次的可用时间。未完成的任务在下一班次从原进度继续；若某班次内做完了全部任务，剩余时间丢弃，下一班次从任务 0 重新开始。求每个班次结束后剩余的未完成任务数。约束：长度 ≤ 1e5，值 ≤ 1e9。

## 我的思考

耗时：20min，主体思路理解完题目即刻确定，但对TreeMap不够熟练，导致耗时略长。
思路：对于每一个任务，我需要维护当前跑到哪一个任务了，完成了多少。
当一轮跑完所有任务后，需要丢弃剩余时长。
对于当前轮，需要找到小于等于当前时长的任务时长前缀和，立刻想到红黑树。
时间复杂的O(n+m)logm 可以接受。
LC已经AC
（写完后想起，实际上不必用红黑树，二分查找复杂度一样，而且没有拆箱）

## 卡点

- TreeMap 不够熟练，导致耗时略长。

## 关键点

- 对任务时长做前缀和，每个班次用"累计可用时长"查找 ≤ 它的最大前缀和，即得已完成任务数。
- 查找可用二分代替红黑树，复杂度相同且没有拆箱。
