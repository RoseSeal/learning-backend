# 3676. 碗子数组的数目

记录：独立 · 未超时 · 首交通过 · 模拟

## 我的思考

**题意**：数组 `nums` 元素互不相同。子数组 `nums[l..r]` 称为碗，需要同时满足两个条件：长度不小于 3，且 `min(nums[l], nums[r]) > max(nums[l+1..r-1])`。求碗的个数。

**约束**：`3 <= n <= 1e5`，`1 <= nums[i] <= 1e9`。

- 把数值看成高度，碗就是两端都严格高于中间的子数组。
- n 为 1e5 量级，允许的复杂度至多 O(n log n)。
- 朴素解：枚举所有子数组并检查，O(n²)，不可行。
- 按「较矮端点」枚举：每个碗恰好有一个较矮端点，它要么是左端点，要么是右端点。
  - 固定 i 为较矮的右端点：另一端只能是 i 左侧第一个比它大的元素 j。j 和 i 之间都比 nums[i] 小；j 再往左的元素，中间都夹着比 nums[i] 大的 nums[j]，不能和 i 构成碗。所以最多一个碗，条件是 `i - j + 1 >= 3`。
  - 较矮的左端点同理，镜像处理。
  - 两类相加即为答案，不重不漏。
- 实现：维护单调栈，栈底到栈顶递减。一次遍历同时完成两个方向：
  - 弹栈时，i 是 j 右侧第一个更大元素，对应「j 为较矮左端点」，`i - j > 1` 时计数；
  - 弹栈结束后，栈顶是 i 左侧第一个更大元素，对应「i 为较矮右端点」，`i - j > 1` 时计数。
- 自测用例：`[2,5,3,1,4]`，碗为 `[5,3,1,4]` 和 `[3,1,4]`，答案 2；`[1e9, 1e9-1, 1e9-2]`，长度 3 且递减，答案 0。

## 复杂度

- 时间：O(n)，每个下标最多入栈、出栈各一次。
- 空间：O(n)，单调栈。

## 注意

- 下标条件初次写成 `j - i + 1 >= 3`，被追问后改正为 `i - j + 1 >= 3`（i > j）。
- 栈的单调方向要说准确：这是单调栈，栈底到栈顶递减，不是「小顶堆」。
- 空栈时用 `n` 作哨兵，要依赖 `i - n < 0` 才不计数，属于隐式约定。直接写 `!stack.isEmpty() && i - stack.peek() > 1` 更清楚。
- 口述是左右两遍镜像，代码是一遍完成。面试时要交代弹栈和栈顶分别对应哪个方向的计数。
- 模拟中三个关键论证都是被追问后才说出：为什么只看最近的更大元素、为什么不重不漏、栈的不变量。下次要主动讲。
