# 3844. Longest Almost-Palindromic Substring

记录：独立 · 未超时 · 首交通过

## 我的思考

题意：给定字符串 s，求最长的连续子串长度，要求该子串删除恰好一个字符后变为回文串（准回文串）。
约束：2 <= s.length <= 2500，s 仅含小写字母。

- 观察：任何回文串都是准回文串。奇数长度删中心得到偶数长度回文；偶数长度删中心两字符之一得到奇数长度回文。
- 约束映射：n <= 2500，允许 O(n²)，确定使用区间 DP（Interval DP）。
- 两张表：
  - `isPalind[i][j]`：s[i..j] 是否为回文。
  - `isAlmost[i][j]`：s[i..j] 是否为准回文。
- 按长度 len 从小到大枚举区间，转移：
  - `isPalind[i][j] = s[i]==s[j] && (len<=2 || isPalind[i+1][j-1])`
  - `isAlmost[i][j] = (s[i]==s[j] && (len<=2 || isAlmost[i+1][j-1])) || isPalind[i][j-1] || isPalind[i+1][j]`
- len 递增，遇到准回文直接更新 ans = len。

## 卡点

- 内层区间为空的边界条件写反：应为 `i + 1 > j - 1`，初版写成 `i + 1 < j - 1`。提交前自测发现，定位耗时约 10min，最终改用 `len <= 2` 表达。

## 关键点

- 准回文的转移按删除位置分三类：删左端（`isPalind[i+1][j]`）、删右端（`isPalind[i][j-1]`）、删内部（首尾相等且内层为准回文，`isAlmost[i+1][j-1]`）。三类互斥且穷尽，递推的正确性由此成立。

## 复杂度

- 时间 O(n²)，空间 O(n²)（两张 n×n boolean 表，n=2500 时约 12.5MB）。

## 注意

- 区间 DP 的"内层为空"判断统一用长度写（`len <= 2`），比比较下标方向更不容易写反。
- 面试时要主动讲出上面的三类删除位置分类，这是递推正确性的承重步骤。
- 替代解：中心扩展（Expand Around Center），第一次失配时分两支（跳过左字符 / 跳过右字符）继续扩展。时间同为 O(n²)，空间 O(1)。
