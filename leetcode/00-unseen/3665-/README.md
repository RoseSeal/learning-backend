# 3665. 统计镜子反射路径数目

记录：独立 · 未超时 · 首交通过 · 模拟

## 我的思考

**题意**：`m x n` 的 0/1 网格，1 表示镜子。机器人从 `(0,0)` 出发，到达 `(m-1,n-1)`，每步只能向右或向下。

- 向右移入镜子：被转向下方，进入镜子正下方的格子；
- 向下移入镜子：被转向右方，进入镜子正右方的格子；
- 反射后落到的格子仍是镜子：按新的进入方向继续反射；
- 反射到网格外：整条路径无效。

只要中间任何一步的选择（向右还是向下）不同，就算不同路径；试图进入、然后被反射的镜子格也算在轨迹里。答案对 1e9+7 取模。

**约束**：`2 <= m, n <= 500`，起点和终点保证不是镜子。

- mn 最多 2.5×10⁵，允许 O(mn) 或 O(mn log mn)。
- 这是网格路径计数的变种，镜子本质上是一条转移规则。
- 只用一个数组的话，遇到连续的镜子要递归寻找落点；按方向拆成两个数组 `right`、`down`，就不需要递归。
- 状态：`right[i][j]` / `down[i][j]` 表示离开 `(i,j)` 时向右 / 向下的路径数。
- 转移：进入 `(i,j)` 的来源只有两个：上方的 `down[i-1][j]`（向下进入）和左方的 `right[i][j-1]`（向右进入）。
  - 空格：`right[i][j] = down[i][j] = down[i-1][j] + right[i][j-1]`；
  - 镜子：`right[i][j] = down[i-1][j]`，`down[i][j] = right[i][j-1]`。
- 初值：只需要第 0 行的 `down`。`down[0][0] = 1`，然后向右扫描，每格置 1，遇到镜子时置 1 后停止。
- 第 0 列：`right[i][0] = down[i-1][0]`；空格时 `down[i][0] = down[i-1][0]`，镜子时 `down[i][0] = 0`。
- 答案：终点保证是空格，所以 `right[m-1][n-1] = down[m-1][n-1]`，取哪个都可以。
- 滚动数组：保留上一行的 `curDown`，当前行用 `nexRight`、`nexDown`；每行结束后交换 `curDown` 和 `nexDown`。
- 溢出：两个小于 MOD 的值相加，最大约 2×10⁹，小于 int 上限 2147483647。
- 自测用例：`[[0,1,0],[0,0,1],[1,0,0]]`，三行结束后的 `down` 依次为 `1 1 0`、`1 2 2`、`0 3 5`，答案 5。

## 注意

- 思路没讲就开始写代码。应先口述状态含义、转移和初值，得到认可后再写。
- 「不同路径」最初定义为「经过的格子完全相同就是同一条」，没有说明镜子格算不算经过。正确理解是：被反射的镜子格也算轨迹的一部分，等价于按每一步的选择序列区分。
- 出界排除只答了「自然排除」，没有讲出机制。实际机制是：出界的路径数只落在 `right[i][n-1]` 和 `down[m-1][j]`（j < n-1）里，这些值不会被任何转移读取。
- 自测用例中没有任何路径被反射出界，没有覆盖上面这个机制。自测要覆盖自己声称成立的结论（G2）。
- 第 0 行遇到镜子时「先置 1 再 break」，这是承重的初值，写代码时应主动说明理由。
