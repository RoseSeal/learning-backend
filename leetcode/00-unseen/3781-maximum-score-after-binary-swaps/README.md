# 题号. 交换后的最大分数

记录：独立 · 未超时 · 首交未过

## 我的思考

题意：数组 nums 与二进制串 s 等长，s 中为 '1' 的位置贡献对应的 nums 值；可以把任意 "01" 交换成 "10"（即 `1` 左移），次数不限，求最大分数。n <= 10^5，nums[i] <= 10^9。

思路：`1` 只能左移，所以每遇到一个 `1`，就从它左侧（含自身）的前缀里「提款」一个当前最大值。从左往右扫描，用大顶堆维护前缀中尚未被取走的元素，遇到 '1' 就弹出堆顶并累加。
