# 3703. 移除K-平衡子字符串

记录：独立 · 未超时 · 首交未过

## 我的思考

题意：字符串只含 `(` 和 `)`。k-平衡串定义为 `(` * k + `)` * k。反复删除所有不重叠的 k-平衡子串并把剩余部分拼接，直到不存在 k-平衡子串，返回最终字符串。

约束：2 <= n <= 1e5，1 <= k <= n/2。需要 O(n) 或 O(n log n)。

把"连续的 `(` 加上连续的 `)`"看作一个单元，单元内最多可删 ⌊min(左, 右)/k⌋·k 个。删除后单元可能与相邻单元拼接成新单元，继续删除。用栈维护历史单元，当前单元能与栈顶链接（栈顶是纯 `(`，或当前是纯 `)`）时就合并、删除，重复直到不能链接，再压栈。

重写版：栈中存游程，正数表示 `(` 的个数，负数表示 `)` 的个数。压入字符时如果和栈顶游程同号，就并入栈顶，否则新开一个游程。只在压入 `)` 后、栈顶恰好等于 -k 且下一层 >= k 时删除：弹出 `)` 游程，`(` 游程减 k，减到 0 就弹出。最后按栈中游程依次展开输出。

## 卡点

- 版本 1：统计完一个单元就直接删除、直接加入结果。没有意识到后续单元会和前一个单元拼接。
- 版本 2：用 pre 记录前一个单元。没有意识到合并删除后的结果还会继续影响更前面的单元（连锁）。首交的是这一版，看到未过的用例后才改成用栈（版本 3）。

## 关键点

- 删除会暴露新的相邻关系，并且可能连锁多层，因此要用栈保存全部历史，不能只记前一个。

## 复杂度

时间 O(n)：每个游程（单元）最多入栈一次、出栈一次。
空间 O(n)。

## 注意

- 重写版比原版简单：合并在压入字符时自然完成，删除只由压入 `)` 触发，不需要 canLink 的两种情况和合并循环。
- 只需判断 `)` 游程 `== k`：它只会逐个 +1，不会跳过 k；而且第一次到 k 时如果删不掉，下面的 `(` 游程以后也不会再变长，这段 `)` 永远删不掉。
