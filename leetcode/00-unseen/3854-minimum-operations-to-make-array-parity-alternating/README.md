# 3854. Minimum Operations to Make Array Parity Alternating

记录：独立 · 未标超时 · 首交未记录（迁移自旧 unseen 记录）

## 题意

整数数组，每次操作把某个元素加 1 或减 1，使相邻元素奇偶性交替。返回 [最少操作次数, 在恰好用该次数得到的所有交替数组中 max - min 的最小值]。长度为 1 的数组视为已交替。

## 我的思考
