# 3840. House Robber V

记录：独立 · 未超时 · 首交通过

## 我的思考

题意：n 间房屋，`nums[i]` 为金额，`colors[i]` 为颜色。相邻且同色的两间房屋不能同时偷，求最大金额。
约束：1 <= n <= 10^5，1 <= nums[i], colors[i] <= 10^5。总和最大约 10^10，需要用 long。

用两个状态做线性 DP，每步 O(1) 转移：
- `rob`：偷当前房屋的最优值
- `skip`：不偷当前房屋的最优值

颜色约束只作用于"相邻两间都偷"这一种转移：i-1 偷且 i 偷，只有在 `colors[i] != colors[i-1]` 时才允许。

## 卡点

- 审题误读：一开始理解成"连续同色段内只能偷一个"，并按这个理解写出了段内状态机：`rob` 表示本段已偷，`skip` 表示本段未偷，同色时 `nextSkip = max(skip, 0)`。用反例 nums = [1,1,1]、colors = [1,1,1] 向面试官澄清后确认：约束只针对相邻，答案是 2（偷下标 0 和 2）。随后把 `nextSkip` 放宽为 `max(skip, rob)`，修正后 AC。

## 关键点

- 约束只限制"相邻都偷"，所以只影响 rob → rob 这一条转移；`skip` 可以无条件地从 `max(skip, rob)` 转移过来。

## 复杂度

- 时间 O(n)，空间 O(1)。

## 注意

- 从段级版本做最小改动后，`rob` 的语义变成混合定义：要么第 i 间被偷，要么第 i-1 间被偷且与第 i 间同色。代码仍然正确，但同色时的 `rob + 0` 分支是冗余的，因为 `rob_{i-1} <= max(skip, rob)`，这个值已被 `skip` 覆盖。
- 更干净的写法：`nextRob = (isSameColor ? skip : max(skip, rob)) + curr`。这样 `rob` 严格表示"第 i 间被偷"，追问状态定义时一句话就能讲清楚。
