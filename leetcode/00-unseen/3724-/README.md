# 3724. 转换数组的最少操作次数

记录：独立 · 未超时 · 首交通过

## 我的思考

题意：给定长度为 n 的 nums1 和长度为 n+1 的 nums2。每次操作选一个下标 i，可以把 nums1[i] 加 1、减 1，或者把 nums1[i] 当前的值追加到数组末尾。求把 nums1 变成 nums2 的最少操作次数。

约束：1 ≤ n ≤ 10⁵，1 ≤ nums1[i], nums2[i] ≤ 10⁵。

思路：
- 前 n 位按位求差，累加 |nums1[i] - nums2[i]|。
- 最后一位 last = nums2[n] 单独处理：长度要多 1 而且不能删元素，所以恰好追加一次，追加本身算 1 次操作。
- 选下标 i，令 a = nums1[i]，b = nums2[i]。nums1[i] 从 a 走到 b 的途中，可以在任意一个中间值上追加。如果 last 落在 [min(a,b), max(a,b)] 内，副本不需要额外调整。否则额外代价是 last 到两端点距离的较小值。对所有 i 取最小。
- 答案 = 差值之和 + 最小额外代价 + 1。

正确性：设追加时 nums1[i] 的值为 v，总代价 ≥ |a−v| + |v−b| + |v−last|。其中 |a−v| + |v−b| ≥ |a−b|，取等当且仅当 v ∈ [a,b]。所以最优的 v 是区间内离 last 最近的点，额外代价等于 last 到区间 [a,b] 的距离。

## 注意

- 差值之和最大约 10¹⁰，ans 必须用 long。
- 判断 last 是否在区间内时，不要用 (last−a)*(last−b) ≤ 0，int 会溢出。可以统一写成 max(0, lo − last, last − hi)。
- 面试时要把「恰好追加一次」和「v 必须在 [a,b] 上」两步讲出来，不能只说「显然」。
