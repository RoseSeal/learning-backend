# 3970. Shortest Path With At Most K Consecutive Identical Characters

记录：独立 · 未标超时 · 首交未记录（迁移自旧 unseen 记录）

## 题意

有向加权图，每个节点有一个小写字母标签。求从 0 到 n-1 的最小路径权值，要求路径上标签按顺序拼接后，连续相同字符不超过 k 个；不存在返回 -1。约束：n、边数 ≤ 5e4，w ≤ 1e4，k ≤ 50。

## 我的思考

读题：题目约束同类节点不能重复去超过k次。
这里dijk一样用。
只需要要记录currSame，如果下一个节点和当前节点同类就加加，否则清零。
每个节点可能都得维护一个currSame。
那节点不同代价不同currSame，这就有两个变化了，好像不能简单的代价最低最好了？
还是有支配关系，
currSame和代价都大就没用，curSame或者代价只要有一个小，就保留。
这样应该可行。

耗时 28min。

## 卡点

## 关键点

- 状态为（节点，当前连续同标签数 currSame），在状态图上跑 Dijkstra。
- currSame 和代价都更大的状态没有用；只要有一项更小就保留（支配关系）。

## 主流解对照

## 复杂度

（补）状态数 n·k，时间 O(k·(n + E)·log(k·E))；空间 O(n·k)。
