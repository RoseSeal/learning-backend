# 3650. 边反转的最小路径总成本

记录：独立 · 未超时 · 首交通过 · 模拟

## 我的思考

题意：有向带权图，n 个节点，edges[i] = [u, v, w] 表示 u→v，成本 w。每个节点的开关最多用一次：到达 u 时，可以选 u 的一条入边 v→u，把它反转为 u→v 并立即走过去，成本 2w，反转只对这一次移动有效。求 0 到 n−1 的最小成本，不可达返回 -1。

约束：2 ≤ n ≤ 5e4，1 ≤ E ≤ 1e5，1 ≤ w ≤ 1000。

本质是求有向图最短路，额外加了反转机制。

最初想法：先跑一遍 Dijkstra 得到最小距离，再把所有边视为反转（不真的反转，只交换起点终点）……

再想发现不需要，这个限制实际上不起约束作用：
1. 反转只是临时改变方向。最短路本来就不会重复走同一条边，重复走意味着出现环，非负权下环不会让答案变优。
2. 每个点的开关只能用一次，而最优路径本来就是每个点只经过一次，原因相同。

所以直接跑 Dijkstra：建邻接表时入边也加进去，代价翻倍。

## 关键点

- 归约：把每条 u→v 额外加一条 v→u、权 2w 的边，在增广图上跑普通 Dijkstra。
- 归约成立的理由：w ≥ 1，最短路是简单路径，每个节点最多离开一次，所以每个开关最多用一次，约束自动满足。

## 复杂度

- 时间 O((V+E) log E)，与 O(E log V) 同阶
- 空间 O(V+E)
- 溢出：简单路径最多 n−1 条边，距离不超过约 1e8，int 安全

## 注意

- 建图方向：原边 e = [u, v, w]，加 u→v（w）和 v→u（2w）。
- 变量命名：当前距离不要和边权共用 `w`；起点终点用 `u, v`，不要用 `out / in`。
