# 3910. Count Connected Subgraphs with Even Node Sum

记录：H1 · 超时 · 首交未记录（迁移自旧 unseen 记录）

## 题意

无向图，节点值为 0 或 1。统计满足以下条件的非空节点子集 s 的个数：s 的诱导子图连通，且 s 中节点值之和为偶数。约束：n ≤ 13。

## 我的思考

最初思路（按节点顺序做计数 DP）：

我的思路是，首先建图，按节点顺序，每个节点只保留这样的边：(v,u)，u为本节点，v为顺序小于本节点的节点。
然后遍历图，记录每个节点的节点和为偶数的数量，以及和为奇数的数量。
然后每个节点遍历时，
遍历本节点每条边，
设边为(i,curr)，若curr节点值为偶数，
curr_偶数_count += j_偶数_count + 1；
curr_奇数_count += j_奇数_count；

若本节点节点值为奇数，则：
curr_偶数_count += j_奇数_count；
curr_奇数_count += j_偶数_count；

最终统计所有节点的偶数节点和子图数量

## 卡点

- 一开始就看到 n = 13 并考虑暴力枚举，但"图的子集枚举 → bitmask → O(2^n)"这个先验映射脑子里没有，误以为是 13!，转而去想如何复用。
- 知道总数是 2^13 之后，如何翻译成代码又卡了一下，提示位运算后才想到 bitmask。
- 并查集和 bitmask 的实现细节（取出 mask 中所有节点、判断节点和）不熟，实现 + debug 用了 40min。

## 关键点

- n = 13，子集总数为 C(13,1) + C(13,2) + … = 2^13 = 8192，每个子集检查连通性代价 O(n) 级，总量约 1e5，可行。
- 用 bitmask 枚举所有子集，再判断奇偶和与连通性。
