# 3933. Largest Local Values in a Matrix II

记录：H1 · 超时 · 首交未记录（迁移自旧 unseen 记录）

## 题意

n×m 非负整数矩阵。非零格 (r, c) 值为 x，检查其行距与列距都在 x 以内的格子（越界忽略，行距和列距同时恰为 x 的四个角也忽略），若其中没有大于 x 的值则为局部最大值。求局部最大值个数。约束：n、m、matrix[i][j] ≤ 200。

## 我的思考

我的思路是： 显然更小的局部最大值的结果可以被更大的局部最大值复用，反过来不行。 当一个较大的局部最大值检索到一个更小的局部最大值时，这个更小的局部最大值覆盖的范围可以放心跳过。 如何利用这个性质， 我打算先把值和下标转成数组，然后排序，这一步Onlogn 然后就可以从小到大的比对候选者。 对于当前候选者，如果它成功了，那么把它覆盖的范围都标记为已经访问，并且对应格子的值改成应该向右跳跃的长度。 这一步摊还复杂度应该是On 这个思路可行吗？

## 关键点

- n、m、matrix[i][j] 都 ≤ 200，预处理每行任意区间的最大值后，对每个候选格逐行检查即可。
