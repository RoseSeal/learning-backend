# 3728. Stable Subarrays With Equal Boundary and Interior Sum

记录：独立 · 未超时 · 首交通过

## 题意
给定数组 capacity，长度 ≤ 1e5，元素范围 ±1e9。统计满足以下条件的连续子数组 [l, r] 的个数：长度 ≥ 3，capacity[l] == capacity[r]，且两端点之间的元素和等于端点值。

## 我的思考
- 数据范围排除 O(n²)。
- 拆成三个子问题：求任意子段和（用前缀和）、找相同值（用 nextSame 链）、统计同时满足两者的 pair 数。
- 逐 pair 检查最坏是 O(n²)，不可行。
- 尝试剪枝：对固定的 l，沿 nextSame 找到 r1 后，认为更远的 r2 中间至少含两个 v，因此不可行。卡在 v == 0 的情况。
- 转向：对每个右端点 idx，它需要的左端点前缀是固定的 `pre[idx] − 2·v`，用 map 存储并查询即可。
- 实现细节：
  - 遍历顺序：计算 nextSame 的 map 里恰好存着每个值第一次出现的下标，直接遍历它的 values 作为每条链的头。
  - 相邻同值不能配对（长度为 2）：用 wait 变量延迟一格插入。非法元素一次最多只有一个（只有紧挨着才非法），不需要队列。

## 卡点
- 剪枝论证本身不成立：只有 [l, r1] 稳定时，才有 interior(l, r1) = v；元素可以为负，interior(r1, r2) = −v 时 [l, r2] 仍然稳定。反例：[1, 1, 1, −1, 1]。卡住的原因不是 v == 0，而是这个方向错了。

## 关键点
- 等式变形：设 v = capacity[l] = capacity[r]，条件 pre[r] − pre[l+1] = v，即 pre[l] = pre[r] − 2v。对固定的 r，所需的 l 只由一个值决定，可以用哈希表计数。

## 复杂度
- 时间 O(n)（哈希期望），空间 O(n)。

## 注意
- wait 不能用 −1 当哨兵：前缀和可以是任意 long 值，取值没有空隙，用不了数值哨兵，要用 null 或单独的 flag。
- wait 必须声明在每条链的循环内部：声明在外层会把上一条链的残留值带进下一条链。单条链测试发现不了，链交替时才会暴露。
- `value * 2` 在 ±1e9 下最大为 2e9，没有溢出，但余量很小，应写 `2L * value`。
- 更简单的写法：从左到右扫描，处理 r 前插入 l = r−2 的 key (capacity[l], pre[l+1])，再查询 (capacity[r], pre[r] − capacity[r])。滞后两格插入天然满足长度 ≥ 3，不需要 nextSame 和 wait。
