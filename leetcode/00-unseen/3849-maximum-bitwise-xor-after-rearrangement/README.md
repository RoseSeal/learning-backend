# 3849. Maximum Bitwise XOR After Rearrangement

记录：独立 · 未超时 · 首交通过

## 我的思考

题意：给定两个等长的二进制字符串 s 和 t。s 固定不动，t 的字符可以任意重排。求 s 与重排后的 t 按位异或（XOR）能得到的最大值，以二进制字符串形式返回。

思路：
- t 可以任意重排，所以它只剩下两个计数：count1 个 1 和 count0 个 0。
- 从 s 的最高位开始遍历，贪心匹配：s 当前位是 0 时尽量配 1，是 1 时尽量配 0。配上了这一位就是 1，补位用完了就只能配相同的比特，这一位是 0。

写法：用 `count[2]` 计数，`count[curr ^ 1]` 就是当前位需要的补位比特，把两种情况统一成一个分支。

## 卡点

- 想到"要从最高位开始"之后，下意识把遍历写成了 idx 从 n-1 到 0，但 sb 仍是正向追加，两个方向不一致。题目给的样例恰好能过，是提交前自己造随机用例才发现的。debug 用了约 5min。

## 关键点

- t 可以任意重排，所以它等价于 (count0, count1) 两个计数。
- 高位优先的贪心：每一位优先放补位比特。

## 复杂度

- 时间 O(n)
- 空间 O(n)（输出字符串），计数本身 O(1)

## 注意

- 贪心成立的依据：第 i 位的权重 2^i 大于所有低位权重之和 2^i − 1，所以高位取 1 永远优于低位的任何组合。交换论证：如果某个最优解在第一个与贪心不同的位 i 上取了 0，就把 t 在 i 处与更低位 j 处（补位比特所在位置）的比特交换。i 位变成 1，j 位最多损失 2^j < 2^i，结果严格更大，矛盾。
- 字符串的下标 0 就是最高位。遍历方向必须和输出的追加方向保持一致。
- 这次的 bug 样例测不出来，是靠自造随机用例抓到的。
