## 题意

网格从左上走到右下（只能向右或向下），路径代价为路径上所有格子值的异或，求最小代价。约束：n·m < 1e3，grid[i][j] ≤ 1023。

本题思考：
无约束后缀下，异或操作无偏序可供压缩。

## 卡点

- 暴力路径数约 2^min(n,m)，最大到 1e9 级，不可行；最小化中间值也不行，因为更小的中间值和后续异或可能得到更大的终值。
- 看到了 grid[i][j] < 1024，但完全没想到它有什么用，这类题型没见过。

## 关键点

- 异或在无约束后缀下没有偏序可供压缩。
- 值域只有 1024 种，对每个格子记录所有可达的异或值，复杂度 1024·mn ≈ 1e6。
