## 复盘笔记

# 3858

## 题意

m×n 整数矩阵，每行恰好选一个数，求所选数按位或的最小值。约束：m·n ≤ 1e5，值 ≤ 1e5。

## 我的思考

本题暴露：对模版反应太慢，一开始尝试找偏序支配关系，但失败。然后思考trie树，想到从最高位向下处理，如果某一位必须选1，那么本位对其他行就不产生约束，那么这些行的trie树就需要表达0/1两个分支都走，于是纠结在trie树如何表达0/1都走，最终发现不需要表达，只需要表达「必须走1」和「其余」两种情况即可。
最终发现得到的解法正是按位贪心。
这是直接建模能力强的一种体现，同时也是模版方法召回能力相对偏弱的一种体现。

## 卡点

- 一开始尝试找偏序支配关系，失败。
- 转而思考 trie：从最高位向下，若某位必须选 1，该位对其他行就不再产生约束，于是纠结 trie 如何表达"0/1 都走"。

## 关键点

- 不需要表达"0/1 都走"，只需区分"必须走 1"和"其余"两种情况，这正是从高位到低位的按位贪心。
