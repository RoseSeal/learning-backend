## 复盘笔记

# 3905

## 题意

n×m 网格，若干源点带初始颜色，其余为 0。每个时间步，已着色格子同时向上下左右的未着色格扩散；同一步有多种颜色到达同一格时取最大颜色。求最终网格。

## 我的思考

我一开始打算标记本轮访问过的坐标。然后访问一个坐标就看是否本轮访问过，如果是就可以覆盖更新。
但是用set记录int[]坐标，我记得好像比对的是地址而不是值，如何让set去比较值，我忘记了。又想到空间复杂度已经是Omn，于是改成每轮new一个boolean[][]来记录。
但是超时了，因为这样时间复杂度就是Okmn（k为bfs的代数）了。

我还卡了另外一个bug，
写成了这样：

```
                for (int[] dir : dirs) {
                    int ni = i + dir[0];
                    int nj = j + dir[1];
                    if (ni < 0 || ni >= n ||
                        nj < 0 || nj >= m ||
                        ans[ni][nj] != 0 && times[ni][nj] != time
                    ) continue;
                    ans[ni][nj] = Math.max(ans[ni][nj], color);
                    times[ni][nj] = time;
                    queue.offer(new int[]{ni, nj});
                }
```

这段代码把两个本该分开的动作合到了一个分支里：

更新颜色：同一层里，一个格子可以被多个父节点反复更新，取 max；
入队：一个格子只能入队一次，就是第一次被染色的时候。

过滤条件只挡掉了"更早层已经定色"的格子。本层已经染过色的格子（times == time）会通过过滤，于是每个父节点碰到它都会再入队一次。

## 卡点

- 想用 Set 记录本轮访问过的 int[] 坐标，忘了 Set 对数组比较的是地址而不是值。
- 改为每轮 new 一个 boolean[][]，时间复杂度变成 O(k·m·n)，超时。
- 把"更新颜色"和"入队"合并到一个分支，导致本层已染色的格子被重复入队。

## 关键点

- 更新颜色：同一层里一个格子可以被多个父节点反复更新，取 max。
- 入队：一个格子只能入队一次，就是第一次被染色的时候。
- 用 times[][] 记录每格被染色的层号，区分"本层已染"和"更早层已定色"。
