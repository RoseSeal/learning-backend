## 复盘笔记

# 3923

## 题意

三维点集（坐标取值 0–6）。每一代由此前所有代中任意两个坐标不同的点取逐维向下取整中点生成；求 target 最早出现在第几代，已在初始点中返回 0，不可达返回 -1。

## 我的思考

我在想答案是不是一定只需要两个点反复迭代就可以迭代出来。
如果我们可以确定：a和b的后代，不可能被c用到来产生最优解，就很简单了。
但是这条性质很诱人，却不是显然成立的
也就是：对任意可达的 `target`，如果它最早在第 `k` 代出现，那么存在两个初始点 `a,b`，仅使用 `a,b` 以及它们产生的后代，也能在不晚于第 `k` 代得到 `target`。

我没找到反例，因为题目限制坐标取值为0到6。

我想到思路了！
只需要一直维持一个最小距离向量（绝对值，因为正负不重要）
然后反复生成下一代，当最小距离为零，就返回代数，当最小距离某一个维度在下一代不下降，就认为不可达

不对：
一维情况下：初始点：0, 3
target：2

第一二代最小距离都是1，第三代找到答案。
…

…重新思考一下问题。
我觉得完全可以枚举，唯一的问题是找到一个停机判据。
最简单的判据就是：是否有新点产生。
问题是这么弱的判据是否能够接受。
等等！我想到了，我之所以觉得可能不能接受，是因为点的状态空间有7^3，可能很大。但其实并不是任意出现的，因为每条维度不能独立生成，必然是两个点间两两生成，也就是不是3个独立自由度，它们是绑定的。
…而且，甚至，写出来才发现：7^3并没有多大…

## 卡点

- 猜想"只需两个初始点反复迭代即可得到最优解"，诱人但不显然成立；没找到反例（坐标只在 0–6 取值）。
- "维护最小距离向量、某维不下降即判不可达"的思路被反例推翻：一维初始点 0、3，target 2，第一二代最小距离都是 1，第三代才得到答案。

## 关键点

- 直接逐代枚举，停机判据为"本代是否产生新点"。
- 坐标限制在 0–6，状态空间最多 7^3 = 343 个点，枚举完全可行。

（补）点数 V ≤ 343，每代只让新点与已有点配对，总配对 O(V^2)；空间 O(V)。
