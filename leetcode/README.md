# LeetCode

Java 算法训练仓库，服务 2027 年暑期实习后端面试。

## 文件
- `EXECUTION.md` — 执行规则（每周结构、单次流程、记录、标记、双周检查）
- `ROADMAP.md` — 题目清单与状态、R19 重做队列（Console Coding 模块的唯一事实源）
- `00-unseen/` — 陌生题，一题一目录
- `NN-<round>/` — 主线轮次题目，一题一目录（`README.md` 笔记 + `Solution.java`；重做产物在 `reviews/`）
- `insight/` — 横向总结（轮次复盘、专题、专项）
- `legacy/` — 旧轮归档

## 工具
日常流程在 Console Coding 模块完成：陌生题入口 / Daily 选题 → Create Note（`new-lc`）→ 记录栏 → Submit（`lc-submit`，提交并推送）；重做在 Review tab。
